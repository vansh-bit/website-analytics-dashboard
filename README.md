# TechVision CMS + Analytics Dashboard

A full-stack website with admin content management and a custom Google Analytics 4 dashboard.

## Stack
- **TestWebsite:** Express.js, MongoDB, JWT auth, bcrypt
- **Dashboard:** Express.js, Google Analytics Data API v1beta

## Features
- User signup/login with JWT authentication
- Admin panel to edit website content without touching code
- Real-time visitor tracking by country and page
- Historical page views, session data, bounce rate
